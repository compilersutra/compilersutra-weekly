### 1. [GCC] Avoid false dependency for BSF [PR128662]

**What changed**  
BSF, like BSR, leaves its destination unmodified when the source is
zero, so the hardware treats the destination as an input.  The new
X86_TUNE_AVOID_FALSE_DEP_FOR_BSR tuning already clears the destination
before BSR, but BSF was not handled:

**Why it matters**  
Affects X86 lowering / target code generation. Matters for CPU compiler engineering. Lives in the Backend of the pipeline. The same commit touches tests — use those as the reproduce entry point. Primary audience: CPU developers, X86 backend engineers, Backend engineers.

**Who should care**  
CPU developers, X86 backend engineers, Backend engineers
