CompilerSutra Weekly — #001, November 7 2026

What changed in compilers this week.

Welcome to issue #001 of CompilerSutra Weekly, a Saturday newsletter covering developments across LLVM, Clang, GCC, MLIR, AI compilers, GPU compilers, and related toolchains.

Reporting period: 2026-10-30 → 2026-11-06 (UTC, Fri→Fri, end exclusive)
Published: 2026-11-07

Entries below are curated from repository activity and project announcements. Each item is a short technical note with a link to the original source — not a raw commit dump. Full collected data stays on the complete change log.

LLVM

  • Use runCodeGenPipeline in SPIRVTranslate. (3 related commits) e5a911f, 930f2d2, 30a475d.
  • Fold unmasked signed byte loads into D16 high loads. (2 related commits) 6e37cd2, 06f4a14.
  • Clear NoPHIs after SIFixSGPRCopies under the new pass manager. (2 related commits) e2e487d, 73fd9cd.
  • Make m_OneUse ignore debug uses; remove m_OneNonDBGUse. 070b193.
  • Inserting a <1 x Ty> into a <1 x Ty> vector was fixed. 5040db9.
  • Documentation about ABI occupancy was added. c5b99ea.
  • Libsycl: property_list for sycl::queue was implemented. 3b2fe02.
  • Compute known bits for llvm.amdgcn.mul.u24/i24. 60e151d.
  • Combine shifted power-of-two division and nonnegative signed div/rem. 6e5a44f.
  • Compare element sizes in minScalarSameAs/maxScalarSameAs. f5eb672.
  • Do not attach instruction metadata to debug instructions. ffc8376.
  • Don't assert on tied multi-register inline asm inputs. 16f7571.
  • Expand sdiv/srem by constant when G_SMULH splits into legal pieces. 1843ebb.
  • Dominance when legalizing PHI for results of invoke was fixed. 459cd1e.

Clang

  • Support for matrix splat cast was implemented. (5 related commits) 6fff663, 191ca4e, 3c4aa88, 446cfbe, +1 more.
  • SPIR-V target ABI classifier to the LLVM ABI library was added. 12e5222.
  • Local 'cleanup' attribute was implemented. 56f7848.
  • MS ABI with deleted template constructor was fixed. 2abfa10.
  • Pick the default ABI of environment-less triples from the architecture. 80542d2.
  • Matrix support for the step intrinsic was implemented. e2e1703.
  • Support for the Zyhybrid extension was introduced. 743905e.
  • Attach a single callgraph type identifier to function definitions. (5 related commits) c1498de, 8c8f266, 791b53c, df98779, +1 more.

GCC

  • Robin Dapp: RISC-V: Extract subvectors via vec_perm_const. (10 related commits) 8ce5e39, 78873c4, fa20d16, b95850f, +6 more.
  • ICE on enum struct-variant patterns was fixed. (7 related commits) 054a9dd, 8a764a4, 00ea483, f9aee05, +3 more.
  • Intrinsics: Add no-ops for prefetch_{read, write}_instruction. (4 related commits) f967d8b, af127ef, 441900d, 8c999b7.
  • Initial work landed for support for AVX10V1AUX. eb35243.
  • AVX512BMM bitreverse lowering was added. (8 related commits) 6783b73, 5555930, 0841d1b, 18d2e51, +4 more.
  • Port vabd and vaba intrinscs to pragma-based framework. (7 related commits) a364d69, 7d24961, 89a7b7d, da3cb0e, +3 more.
  • Check CF_RETURN bit in ix86_expand_epilogue. (5 related commits) ea93a47, 8855f06, f2de257, 07b484c, +1 more.
  • Throw an error when a global path starts with crate. (4 related commits) 9ff8f5a, cfe4e50, e00493f, 42b194a.
  • Andrew Stubbs: amdgcn: Fix stack size calculation overflow. (2 related commits) adc647a, ef10d55.
  • Igor Shevlyakov: match.pd: Fold same-width signed vector averages. (2 related commits) f088a08, 8835caa.

MLIR

  • Nvvm.mulf Op was added. (3 related commits) aa1bf89, 04e0db5, 0c0e3e7.
  • IndirectAliased (byref) argument lowering was added. dd05b6c.
  • Do not report a negative launch width as a size. (2 related commits) b603a2c, 9640b6a.
  • Skip non-identity layouts in static memory planning. (2 related commits) c389e88, 7823377.
  • Vector unrolling support for apply_scale was removed. fd64c07.
  • Dead values: don't remove used symbols was removed. 305a281.
  • Disallow pure reduction dims in vector.contract. f17edbc.
  • Drop Linalg dependency from transfer full/partial split. d6f914f.
