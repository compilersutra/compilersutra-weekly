Remove clearKillFlags calls (#239892)

projectLLVMstageBackenddomainCPUtargetAArch64levelDeep diveevidenceSource-backed
What changed. Kill flags are no longer permitted on virtual registers, but these contexts may also see physical registers. Those physical register kills are either never set by the time this code runs or are on reserved or constant registers where they carry no information.
Why engineers should care. Affects AArch64 lowering / target code generation. Matters for CPU compiler engineering. Lives in the Backend of the pipeline. Primary audience: CPU developers, AArch64 backend engineers, Backend engineers.
