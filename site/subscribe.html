What is an Atom feed?

Atom is a small XML file that lists new issues in a standard format. Feed readers (Feedly, Inoreader, NetNewsWire, Thunderbird, and many others) poll that file and show you a card when a new Saturday edition is published.

If you open feed.xml in a normal browser, you will often see raw XML. That is expected — the file is for machines/readers, not a styled article page. Your subscription page is this HTML page; the feed stays valid XML.

How to subscribe (step by step)

  1. Copy the feed URL above (https://compilersutra.github.io/compilersutra-weekly/feed.xml).
  2. Open a feed reader and choose Add subscription / Follow / Subscribe.
  3. Paste the URL and confirm. You should see CompilerSutra Weekly with entries like Edition 001.
  4. When we publish next Saturday, the reader shows a new entry with the issue summary and a link to the full HTML edition.

Common readers

  • Feedly / Inoreader (web): Add content → paste feed URL.
  • NetNewsWire (macOS/iOS): File → New Feed → paste URL.
  • Thunderbird: File → New → Feed → paste URL.
  • FreshRSS / Miniflux (self-hosted): Add feed → paste URL.
  • GitHub (not Atom): Watch the repository for commits/releases if you prefer that signal.
