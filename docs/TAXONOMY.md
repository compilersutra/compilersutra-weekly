# Publication taxonomy

CompilerSutra Weekly groups findings for compiler engineers — not generic tech news.

| Bucket | Categories (`sources/*.yaml`) | In scope | Out of scope |
| --- | --- | --- | --- |
| **CPU compilers** | `llvm`, `gcc` | LLVM/Clang, GCC | — |
| **IR & infra** | `mlir` | MLIR | — |
| **GPU compilers** | `gpu` | ROCm/AMDGPU LLVM, Mesa, other **open** GPU compiler work | Proprietary CUDA toolkit / closed binaries |
| **AI / DL compilers** | `ai` | TVM, IREE, Triton, ONNX Runtime, … | Product marketing without sources |
| **Research** | `research` | arXiv PL/AR/compiler papers | Paywalled full-text dumps |

Hosting: GitHub repo + Pages. [CompilerSutra](https://www.compilersutra.com/) only links out (no Vercel research runtime).
